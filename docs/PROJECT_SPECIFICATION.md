# TechAssist

## Overview

TechAssist is a cross-platform IT Support and Cybersecurity Troubleshooting Assistant written in Python.

The application is designed to help IT professionals, students, and home users diagnose common computer and network issues by collecting system information, performing diagnostic checks, and providing guided troubleshooting playbooks.

---

## Problem statement

Many diagnostic tools display technical information but leave users to decide what it means.

TechAssist aims to bridge that gap by combining automated diagnostics with clear troubleshooting guidance.

---

## Target Users

- IT Support Technicians
- Cybersecurity Analysts
- Students
- Home Lab Enthusiasts
- Home users

---

## Version 1.0 Objectives

- Display system information
- Perform network diagnostics
- Check firewall status
- Run basic security health checks
- Provide troubleshooting playbooks
- Export reports
